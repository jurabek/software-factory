= Pipeline Model: Remaining Requirements
:toc:

== Status

The original pipeline proposal has been superseded by the stage-owned execution
refactor. Git foundations, frozen Task configuration, stage projections, pipeline
selection in the application, durable Messages, and advisory quality evidence are
implemented. Their former implementation plans have been removed.

Current module ownership and execution diagrams are maintained in
link:../daemon/REFACTORING.md[Daemon architecture] and
link:../README.md#task-execution-sequence[Task execution sequence].

== Current scope

Configuration requires `plan -> build -> verify -> review`, exactly once in that
order. The earlier optional-review proposal is not the current execution contract.
Each stage owns lifecycle transitions and saved-result reuse; `pipeline.Run`
only orders calls and derives outcomes. Approval, resume, Messages, and exact
retry use that same pipeline.

== Factory home versioning

The original proposal's factory-home version requirement remains outstanding.
Installed `config.yaml` and prompt templates are preserved when already present;
there is no explicit factory-home format version check in daemon startup.

The factory home should record a version. On an incompatible version, startup
must refuse with an actionable message naming the home path and required action.
It must preserve operator-edited prompts. Database schema compatibility checks
are separate from configuration and prompt compatibility.

== Concurrency contract to preserve

Message acceptance, approval, publication, and stage advancement must be
coordinated per Task. Pause or abort must prevent subsequent invocations once
they win. Stage and orchestrator locks are currently separate; this document
does not claim that the refactor established one shared lock boundary.

Retry must preserve recorded inputs and retained Git history, reuse eligible
upstream results, and invalidate downstream results on the selected branch.
Restart and resume must preserve planner approval and avoid duplicate execution.
